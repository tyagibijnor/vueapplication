# Vue.js Practice Projects

A collection of small, independent Vue 3 exercises covering core Vue concepts. Each exercise is a standalone HTML page with its own JavaScript and CSS; there is no shared application shell or build step.

## Projects

| Folder | Topics |
| --- | --- |
| `T0203` | Data binding, methods, and interpolation |
| `T0303` | Events and two-way input binding |
| `T0403` | Event handling, forms, and keyboard modifiers |
| `T0503` | Computed properties and input events |
| `T0603` | Computed full names |
| `T0803` | Computed values and watchers |
| `T0903` | Dynamic classes and inline styles |
| `T1003/5`–`T1003/13` | Progressive event, computed-property, watcher, and styling exercises |
| `T2602` | Data-binding exercise |
| `T74` | Reusable components and friend details |
| `addgoal` | Add and remove goals |
| `assignment1`–`assignment3` | Data binding, events, and reactivity practice |
| `lifecycle` | Component lifecycle hooks and mounting |

`T0403` also includes `assignment.html`, an alternate events exercise.

## Run an exercise

1. Clone or download this repository.
2. Open the folder for the exercise you want to try.
3. Open its `index.html` in a browser. For `T0403`'s alternate exercise, open `T0403/assignment.html`.

The pages load Vue 3 from the unpkg CDN, so an internet connection is required. Alternatively, serve the repository root with a local static server (for example, `python -m http.server 8000`) and visit `http://localhost:8000/<folder>/`. No npm install or build command is needed.
